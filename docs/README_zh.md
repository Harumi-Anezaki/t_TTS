# 文字转语音 (TTS) 应用程序

[English](../README.md) | [日本語](README_ja.md) | [中文](README_zh.md)

## 简介
这是一款利用多种 TTS 引擎（如 edge-tts, gTTS, pyttsx3）将文字转换为语音的桌面应用程序。它配备了使用 `ttkbootstrap` 构建的现代深色模式 UI，并包含可自定义的符号过滤（净化）功能。

**✨ 新功能:** 
- **MP4高亮视频**: 当使用 `edge-tts` 引擎时，您现在可以生成**带有实时荧光黄文本高亮（卡拉OK风格）的明亮模式 MP4 视频**。
- **自动分页**: 长文本会自动分为多个幻灯片（每10行一次），防止文字溢出。
- **倍速与高级 Markdown**: 默认以 2.5 倍速的交互式 HTML 格式输出。通过 Web 浏览器打开时，标题（`#`）、粗体（`**`）、**表格** 和标注（`<aside>`）将完全原生渲染，并根据语音自动滚动和高亮显示。完美保留排版，绝不会出现文本截断。
- **完全后台处理**: 运行过程中不会弹出任何烦人的控制台黑框，实现真正的静默处理。

## 安装指南
本程序使用了便携式的嵌入版 Python 环境，因此您无需在电脑上安装 Python 即可运行。

1. **初始设置（仅需一次）**
   双击本文件夹中的 `setup.bat`。
   程序将自动下载轻量级 Python 环境并将所有依赖库安装到本地的 `bin` 文件夹中。（此操作完全不会修改您的系统设置或注册表）

2. **启动程序**
   双击 `run.vbs`。
   应用程序将在后台立即启动（无黑框）。以后每次只需双击此文件即可使用。

## 卸载方法
如果您不再需要本程序，只需直接删除整个文件夹即可完全卸载。您的电脑上不会残留任何垃圾文件或注册表项。

## 开发者指南
如果您是开发者，程序的源代码存放在 `core` 文件夹下的 `main.pyw` 中。您可以直接使用文本编辑器进行修改，下次启动程序时更改会立即生效。
