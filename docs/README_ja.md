# 音声合成 (TTS) アプリケーション

[English](../README.md) | [日本語](README_ja.md) | [中文](README_zh.md)

## 概要
複数のTTSエンジン (edge-tts, gTTS, pyttsx3) を活用してテキストを音声に変換するデスクトップアプリです。`ttkbootstrap` を用いたモダンなダークモードUIを備え、カスタマイズ可能な記号の自動読み飛ばし（サニタイズ）機能を搭載しています。

**✨ 新機能:** 
- **MP4ハイライト動画**: `edge-tts` エンジンを使用している場合、**リアルタイムの蛍光黄色ハイライトが付いたライトモードのMP4動画（カラオケ風字幕）** を生成できるようになりました。
- **自動ページネーション**: 長い文章を入力しても、最大10行ごとに自動で次の画面（スライド）に切り替わるため文字が見切れません。
- **倍速保存と高度なMarkdown対応**: デフォルトで「2.5倍速のインタラクティブHTML」で保存されます。Webブラウザで開くことで、見出し（`#`）や太字（`**`）はもちろん、**表（テーブル）やコールアウト（`<aside>`）** も完全にネイティブ描画され、音声に合わせて自動スクロール＆ハイライトされます。レイアウト崩れや文字の見切れは一切発生しません。
- **完全バックグラウンド処理**: 処理中の黒いコマンドプロンプト画面を完全に非表示にし、スマートに動作するようになりました。

## セットアップ手順
本アプリはポータブル版の組み込みPythonを利用しているため、お使いのPCにPythonをインストールする必要はありません。

1. **初期セットアップ (初回のみ)**
   このフォルダにある `setup.bat` をダブルクリックしてください。
   自動的に軽量版のPython環境がダウンロードされ、必要なライブラリが `bin` フォルダ内にインストールされます。（PCのシステム設定やレジストリは一切汚しません）

2. **アプリの起動**
   `run.vbs` をダブルクリックしてください。
   アプリが黒い画面を出さずにバックグラウンドで起動します。2回目以降はこのファイルを開くだけで利用できます。

## アンインストール方法
アプリが不要になった場合は、このフォルダを丸ごと削除するだけで完全に消去できます。PCにゴミファイルが残ることはありません。

## 開発者向け
ソースコード本体は `core` フォルダ内の `main.pyw` に格納されています。テキストエディタで自由に編集でき、次回起動時からすぐに変更が反映されます。
